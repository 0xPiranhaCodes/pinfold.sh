# VT conformance matrix

Generated by `crates/pinfold-core/tests/vt_conformance.rs`; do not edit by hand. Each case
feeds its bytes to a fresh 4 × 10 engine and compares what PinFold shows with the result
the reference documents. `cargo test` fails when this file is stale, a passing case
regresses, or a case fails without a known-gap issue. To rewrite it, run
`PINFOLD_UPDATE_CONFORMANCE=1 cargo test -p pinfold-core --test vt_conformance`.

Screens are the rows the window draws, without trailing spaces, between bars; a wide
character's second cell is a space. Cursors are `row,column` from 0.
esctest2 runs as well, through `tests/conformance/esctest.sh`.
