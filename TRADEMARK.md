# Trademark policy

The code is open source under `MIT OR Apache-2.0`. Those licenses do not grant rights
to the "Pinfold" name or logo. This policy does.

## Allowed without asking

- Using the name and logo to refer to the project, for example in articles, talks,
  comparisons and "works with Pinfold" descriptions, as long as nothing implies that
  the project endorses you.
- Distributing unmodified official builds or source releases under the name Pinfold.
- Distribution packaging. Linux distributions, Homebrew and similar package
  collections may keep the name when their only changes are:
  - packaging and build integration,
  - backported security or bug fixes,
  - changes needed to fit the distribution's policies.

  They should note those changes in their packaging metadata.

## Not allowed without permission

- Shipping a modified build under the name Pinfold, other than as covered above. A
  fork that ships modified builds must use a different name and logo. It may say that
  it is "based on Pinfold".
- Using the name or logo in a way that suggests a fork, product or service is official
  or endorsed.
- Registering confusingly similar names, domains or package names.
